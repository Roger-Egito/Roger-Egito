# Roger Egito

Game designer and Unity developer from Brazil. I design games at Ludomancer Studio and lead a VR project at UFF's Media Lab.

Some of my work:

- [Hotel 77](https://roger-egito.github.io/games/hotel-77/): level design, 17 anomaly variants and the lore for a narrative horror game on Steam
- [Cursed Blight](https://roger-egito.github.io/games/cursed-blight/): sole designer and programmer, from a one-page brief to a finished dungeon crawler in about a month
- [Vivenciando o Passado](https://roger-egito.github.io/games/vivenciando-o-passado/): project lead on an educational VR experience for Meta Quest 3
